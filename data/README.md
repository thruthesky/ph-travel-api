# 필리핀 여행 100선 — 여행지 마크다운 작성 규격

파일 위치: `data/<번호 3자리>-<slug>.md` (예: `001-intramuros.md`). 대표 사진은 `images/<같은 이름>.webp`.

여행지를 추가·삭제해도 코드를 고칠 필요가 없다. 빌드 스크립트가 번호로 시작하는 `.md` 파일을 모두 찾아 읽는다(이 README 는 제외).
규격 검사: 저장소 루트에서 `node scripts/build.mjs` — 모든 파일의 앞머리·단락·사진·`place:` 링크를 전수 검사하고, 하나라도 어기면 exit 1 로 끝나 배포되지 않는다.
빌드 결과 JSON 을 웹·앱이 받아 목록 카드와 상세 페이지를 그린다. 형식을 정확히 지킨다.

## 1. 앞머리(front matter) — 정확히 아래 키와 순서, 한 줄에 `키: 값`

규칙: 값에 따옴표를 쓰지 않는다. 목록은 `[가, 나, 다]` 한 줄. 값 안에 콜론(:)은 써도 되지만 줄바꿈은 금지. 모든 키 필수.

```
---
id: 1
slug: intramuros
title: 인트라무로스
title_en: Intramuros
tagline: 스페인 성벽 안에 잠든 마닐라 400년의 기억
island_group: 루손
region: 메트로 마닐라
location: 메트로 마닐라 마닐라시
category: 역사·문화
tags: [유네스코, 성당, 도보 여행, 야경, 사진 명소]
rating: 4.6
latitude: 14.5915
longitude: 120.9736
best_season: 12월~4월 (건기)
duration: 반나절~1일
budget: 1인 약 ₱1,000~2,500
difficulty: 쉬움
airport: 니노이 아키노 국제공항(MNL)
image: images/001-intramuros.webp
image_credit: Diego Delso / CC BY-SA 4.0 / Wikimedia Commons
image_source: https://commons.wikimedia.org/wiki/File:...
gallery: images/001-intramuros-2.webp | images/001-intramuros-3.webp
gallery_credits: 작가A / CC BY 4.0 / Wikimedia Commons | 작가B / CC BY-SA 4.0 / Wikimedia Commons
gallery_sources: https://commons.wikimedia.org/wiki/File:... | https://commons.wikimedia.org/wiki/File:...
summary: 카드와 상세 상단에 보일 2~3문장 요약(한국어 100~160자).
---
```

- image 는 이 폴더 기준 상대 경로다. 사진은 Wikimedia Commons 의 CC·퍼블릭 도메인 사진을 1080px WebP 로 줄여 쓰고, image_credit(작가 / 라이선스 / 출처)과 image_source(원본 페이지)를 반드시 적는다 — CC 라이선스의 저작자 표시 조건이다.
- gallery·gallery_credits·gallery_sources 는 선택 키다. 추가 사진·저작자·원본 주소를 ` | ` 로 나눠 같은 순서로 적는다(저작자 이름에 쉼표가 있을 수 있어 쉼표 대신 ` | ` 를 쓴다). 상세 페이지 헤더에서 대표 사진 다음으로 넘겨 본다.
- latitude·longitude 는 소수 4자리. 가까운 여행지 계산과 지도 열기에 쓴다.
- tagline: 20~32자, 감성적인 한 줄 카피. 마침표 없음.
- island_group: 루손 | 비사야 | 민다나오 중 하나 (팔라완·민도로·롬블론은 루손으로 분류).
- region: 지방·섬 이름 (예: 메트로 마닐라, 바탕가스, 코르딜레라, 일로코스, 비콜, 팔라완, 민도로, 세부, 보홀, 네그로스, 파나이, 사마르·레이테, 시키호르, 수리가오, 카미긴, 북부 민다나오, 다바오, 남부 민다나오 등).
- location: 주(州)·도시 수준의 상세 위치.
- category: 반드시 다음 7개 중 하나 — 해변·섬 | 다이빙·해양 | 산·트레킹 | 폭포·호수·강 | 역사·문화 | 도시·미식 | 자연 경관
- tags: 3~6개, 짧은 명사.
- rating: 4.0~5.0 소수 1자리 (여행자 추천도, 세계적 명소일수록 높게).
- difficulty: 쉬움 | 보통 | 어려움 (접근성·체력 기준).
- airport: 가장 가까운 공항(코드 포함). 
- budget: 현지 1인 1일(또는 투어 1회) 기준 필리핀 페소(₱) 범위. "약"을 붙인다.

## 2. 본문 — 아래 `##` 제목을 이 순서대로 모두 사용 (제목 문구 그대로)

```
## 한눈에 보기
(3~4문단. 이곳이 왜 특별한지, 역사·지형·분위기, 어떤 여행자에게 맞는지)

## 꼭 해봐야 할 것
(6~8개 항목. `1. **항목 이름** — 2~3문장 설명` 형식의 번호 목록)

## 추천 일정
(`### 1일차` 또는 `### 반나절 코스` 같은 소제목 + 시간대별 목록. 일정 길이는 duration 과 맞춘다)

## 가는 방법
(마닐라 출발 기준 필수, 세부 등 다른 출발지 있으면 추가. `### 비행기`, `### 버스·밴`, `### 배` 등 수단별 소제목. 소요 시간·대략 요금·현지 이동수단(트라이시클·지프니·밴·방카)까지)

## 여행 최적기와 날씨
(건기·우기, 태풍 시기, 축제·이벤트 시기, 월별 특징)

## 예상 비용
(마크다운 표 — | 항목 | 예상 비용 | 비고 | 형식, 6~9행: 교통·입장료·투어·숙박·식사·환경세 등. 마지막 문단에 "요금은 2026년 기준 대략치이며 현지 사정에 따라 달라질 수 있습니다." 한 줄)

## 숙소와 먹거리
(추천 숙박 지역과 가격대, 현지 대표 음식·맛집 유형. 특정 업소 이름은 오래 운영된 유명 업소만)

## 여행 팁
(6~10개 글머리표. 실제로 도움이 되는 구체적 조언 — 현금·ATM, 신호, 준비물, 예약, 복장, 사진 명소, 시간대)

## 주의사항
(4~6개 글머리표. 안전·환경 규칙·사기·날씨·건강. 필요하면 `> ` 인용문으로 핵심 경고 1개)

## 함께 가보면 좋은 곳
(3~5개 글머리표. `- **장소 이름** — 거리/이동 시간과 한 줄 소개`. 가능하면 이 100선 목록에 있는 곳을 우선. 100선에 있는 곳은 `- [**장소 이름**](place:<slug>) — …` 처럼 링크를 걸면 앱에서 그 페이지로 이동한다 — 테스트가 slug 존재를 검사한다)
```

## 3. 품질 기준

- 한국어로, 필리핀에 사는 한국 교민 커뮤니티(필고)가 추천하는 친근하지만 정확한 여행 가이드 문체(~합니다/~해요 섞지 말고 "~합니다"체로 통일).
- 본문(앞머리 제외) 한글 기준 3,500~6,000자. 짧고 뻔한 문장 금지 — 구체적 지명·거리·시간·요금·팁을 담는다.
- 사실 정확성이 최우선. 확신이 없는 수치는 범위나 "약"으로 표현하고, 자주 바뀌는 규정(입장 예약제·환경세·관광 제한)은 "최신 공지를 확인" 안내를 붙인다. 필요하면 WebSearch/WebFetch 로 확인한다.
- 이모지 금지. HTML 금지. 이미지 마크다운 금지(대표 이미지는 앞머리의 image 로 표시됨). 링크는 공식 사이트가 확실할 때만.
- 코드 블록(```) 사용 금지.
- 파일 인코딩 UTF-8, 파일 끝 줄바꿈 1개.
