# work/ — 이 저장소의 작업 기록

api-skill 로 이 저장소에서 일할 때 **쌓이는 값**을 모두 여기에 둔다. 스킬(`~/apps/skills/skills/api-skill/`)에는 규칙·방법·기준값만 있고, 개수·현재 상태·작업 기록·사용 횟수는 적지 않는다. 스킬은 여러 저장소가 같이 쓰고, 이 값들은 작업할 때마다 바뀌기 때문이다.

- git 에 넣는다(근거 `sources/` 와 같은 이유 — git 밖에 둔 기록은 잃었다). R2 에는 올리지 않는다 — 배포는 `_site/` 만 올린다.
- 규칙은 스킬의 `references/workspace.md` 에 있다.

| 파일 | 무엇 | 언제 고치나 |
|------|------|-------------|
| `status.md` | 지금 상태 — 항목 수·사진 수·언어·version·data_version·R2 에 올라간 판·남은 일 | 작업을 끝낼 때마다 덮어쓴다. 값은 명령 출력에서 옮긴다 |
| `log.md` | 작업 기록 — 날짜별로 요청·한 일·숫자·배운 것·결정. 새 기록이 위 | 작업을 끝낼 때 한 절을 위에 더한다. 옛 절은 고치지 않는다 |
| `usage.jsonl` | 사용 기록 — 작업 한 번에 한 줄. 검색·외부 API 호출·에이전트·업로드 횟수 | 작업을 끝낼 때 한 줄을 끝에 더한다 |

## usage.jsonl 한 줄의 모양

모양을 보이려는 예시다 — 숫자는 실제 기록이 아니다.

```json
{"at":"2026-11-02T04:10:00Z","task":"075~080번 보강","ids":[75,76,77,78,79,80],"web_search":120,"web_fetch":40,"commons_api":300,"agents":6,"r2_put":0,"r2_mb":0,"version":"<빌드 version>","note":"WebSearch 한도가 차서 WebFetch 로 바꿈"}
```

- `at` 은 작업을 끝낸 UTC 시각, `task` 는 요청 한 줄, `ids` 는 만들거나 고친 항목 번호다.
- 횟수는 센 값만 적는다. 세지 않았으면 키를 빼고, 짐작한 값은 `note` 에 "약"을 붙여 적는다. 0 과 "안 셈"을 섞지 않는다.
- 모르는 키를 더해도 된다(예: `translate_lines`). 있는 키의 뜻은 바꾸지 않는다.
