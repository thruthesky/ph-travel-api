# 미수록 여행지 전체와 추가 1,973개 작업

이 작업은 진행 중이다. 일부 완성본 커밋이나 공개 본문 수집 완료가 전체 요청 완료를 뜻하지 않는다. `progress.json`의 고정 시작판은 `dee9c2e`의 295개이며 최소 목표는 총 2,268개다. 원본 두 목록의 미수록 여행지를 모두 검토·등록한다는 조건도 별도로 남아 있다.

- `baseline.json`: 시작판의 파일 경로·Git 객체·원본 목록 SHA. 이후 작업 개수를 위해 바꾸지 않는다.
- `progress.json`, `net-additions.json`: 전체 목표와 검증된 순증. 예약 번호·사진 준비·후보는 등록 수에 포함하지 않는다.
- `accepted-entry-review.json`: 완성본의 단락·하이라이트·한영·사진·빌드 검증 기록.
- `source-fetch-index.jsonl`, `source-fetch-summary.json`: 1,541개 원본 글의 공개 본문 가용성 점검. 같은 글의 재시도는 마지막 기록이 유효하다.
- `body-candidate-mentions.jsonl`: 본문 제목·강조·표에서 찾은 이름과 글 번호·행. 이름 단서이지 실재 여행지 판정이 아니다.
- `body-candidate-name-groups.jsonl`: 같은 표기를 자동으로 묶은 목록. 동명이소·복합 명칭·표기 차이를 사람이 다시 확인한다.
- `body-candidate-priority-review.jsonl`: 구체적인 장소 낱말과 한영 표기가 있는 하위 제목을 우선 검토하기 위한 일부 목록이다. 음식·일반명사·잘못된 장소도 남을 수 있다.
- `post-body-review.jsonl`: 글별 본문 가용성·자동 추출 수. 서술문 속 모든 고유명사나 원글의 모든 하위 명소를 수동 검토했다고 표시하지 않는다.

공개 본문 원문과 사진 원본·집필 중간 파일은 Git에서 제외된 `_i18n/work/expansion-1973/`에 있다. 회원·댓글 정보는 수집하지 않았다. 원문은 조사 단서이며 최신 사실의 근거로 그대로 전재하지 않는다.

```sh
node work/expansion-1973/crawl-public-posts.mjs
node work/expansion-1973/extract-body-candidates.mjs
```

수집기는 완료된 공개 본문 캐시를 다시 요청하지 않고 미완료·실패 글만 재시도한다. 추출기는 캐시 SHA를 대조한 뒤 당시의 여행지와 대장 별칭으로 이름 일치를 기록한다. 새 항목을 추가한 후 다시 실행하면 이름 일치 판정은 달라질 수 있다. 이름 일치 자체도 실제 수록 범위의 최종 판단이 아니다.

신규 항목은 상세 기준을 유지한다. 사진 원본 10장 확보와 직접 검수, 현재 근거 교차 확인, 한국어 상세 본문과 영어 번역, 10단락과 정수 하이라이트 6개, Codex CLI의 수치 이미지 가공, i18n 검사 뒤 완성 쌍을 통합한다. 같은 작가의 연속 촬영 여행은 한 묶음으로 보고 사진을 중복해 채우지 않는다. 나머지 6언어는 사용자가 승인한 영어 대체이며 실제 번역 완료로 세지 않는다.

각 담당자는 완성 항목을 인계한 뒤 예약 범위의 다음 후보를 계속 조사한다. 부모는 전역 fallback·메타·대장·원본 매핑·빌드·검색·커밋을 통합한다. 일부 커밋 때문에 담당자의 작업을 종료하거나 전체 목표를 축소하지 않는다. 배포·GitHub push·상위 서브모듈 포인터 커밋은 하지 않는다.
