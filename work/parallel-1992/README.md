# 상세 여행정보 병렬 추가

2026-11-17 사용자가 여러 에이전트의 병렬 분담을 명시 지시했다. 시작은 실제 276개이며 최초 268개에 신규 최소 2,000개를 추가하는 목표까지 1,992개가 남았다.

- 항목별 사진 10장·출처 교차검증·상세 한국어/영어 본문을 유지한다.
- 루손 307~326, 비사야 327~346, 민다나오/팔라완 347~366을 분담한다. 루트 367~386은 통합검증과 보충 조사에 사용한다. 번호 예약은 등록이 아니다.
- 실제 완성된 `data/ko`, `data/en`, 사진, `sources`를 검토한 뒤 번역 대체 선언·빌드·사진 검사·검색·대장을 통합한다.
- 개수는 `assignments.json`의 승인 목록과 원본 JSON을 대조한다. 준비 자료와 보류 후보를 등록한 것으로 세지 않는다.
- 공용 meta·대장·진행 기록·커밋은 루트가 담당한다. 에이전트별 조사 기록은 각 전용 하위 폴더에 둔다.
- 사진 변환은 Codex CLI에서만 한다. 이미지 생성이나 내용 변경 없이 Commons 원본을 규격 변환하고 원본과 결과를 직접 확인한다.
- 운영 배포·GitHub push·상위 저장소 포인터 변경은 하지 않는다.
